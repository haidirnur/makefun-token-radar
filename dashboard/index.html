How the value is built

implied = TVL^0.92 × 0.30 × growth × maturity × breadth × category

  • Size. TVL to the power 0.92, so value grows with size but sublinearly: a protocol twice as big is not twice as valuable as a launch.
  • Growth. The 7-day TVL change, clamped to −50%…+150%, weighted 0.60. A protocol shrinking fast scores lower; a hot one scores higher.
  • Maturity. Days since DefiLlama began tracking it, up to 4 years: 0.55 at day zero, rising to 1.00. A long run with no token is a patience premium.
  • Breadth. +4% per extra chain, up to 5 extra chains. Multi-chain reach counts.
  • Category. 1.00, or 0.90 when DefiLlama names no category.
  • Set aside, never ranked. Exchanges, versioned pools, bridges, liquid staking and restaking, and names carrying wrapped, staked or staking, or beginning with an exchange's name: they are claims on a token that already trades, so the board lists them separately with the reason instead of ranking them as launches.

Read this before you farm. “Records no token” is what DefiLlama's record says, never proof a protocol has none: a protocol on this board may still have a token its record does not carry. The implied value is this radar's own claim, not a prediction that a token is issued, when, or at what price. Never pay anyone to claim for you; claim only from a link the protocol itself publishes.
