Token launch radar (model radar-2): ranks every pre-token protocol in the sealed DefiLlama snapshot that can be a standalone launch, by an implied value built from its own figures — sublinear TVL, 7-day growth, age with no token, chain breadth, and a small discount for unnamed categories — with wrapped, staked, bridged and exchange products set aside with the reason instead of ranked, a concrete 7-step farm plan per protocol, and a sortable, filterable dashboard with a detail view, a live-token view and a model sandbox.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
